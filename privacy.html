Studio privacy policy

Last updated: 19 November 2026.

Studio is a private tool used only by the owner of the YouTube channels LastLog and Syv Ulv, on the owner's own computer.

YouTube API Services

Studio uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). By using Studio you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

What it accesses

With the owner's permission through Google sign-in (OAuth), Studio uploads and schedules videos, sets thumbnails and playlists, and reads views, watch time, click rate and audience retention for the owner's own channels. It does not access other channels, comments of other users, or any personal data about viewers.

What it stores and why

The sign-in token and the channels' statistics are stored only on the owner's computer, to compare videos and plan new ones. Nothing is sold, shared with third parties, or used for advertising. Studio uses no cookies.

Retention and deletion

Statistics (such as view counts) and scores derived from them are kept for at most 36 months; any other data received from the API is refreshed or deleted within 30 days. When access is revoked, the stored token is deleted and stored API data is deleted within 7 days. To revoke access at any time, visit the Google security settings page. To ask for deletion, contact the owner through the channel's About page.
